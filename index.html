🔄 Sync con tu Amigo
Exporta tu lista y fusiona la de tu amigo fácilmente. Los IDs son únicos para evitar duplicados.

Exportar mis datos

Descarga un archivo JSON con todos tus negocios y envíaselo a tu amigo para que los fusione en su app.

Fusionar datos de amigo

Carga el JSON que te envió tu amigo. Los negocios nuevos se agregan y los existentes (mismo ID) se actualizan.

Zona de peligro

Eliminar todos los negocios guardados. Esta acción no se puede deshacer. Haz un backup antes.

Cómo funciona el Sync

  1. Tú agregas negocios → pulsas Descargar JSON
  2. Le envías el archivo por WhatsApp/email a tu amigo
  3. Tu amigo pulsa Fusionar JSON y selecciona tu archivo
  4. Los negocios nuevos se añaden, los ya existentes se actualizan automáticamente
  5. No hay duplicados gracias al ID único de cada negocio
